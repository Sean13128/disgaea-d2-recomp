# AB — decouple command-ring recycling

**Implemented in the shared SDK. Real-Metal ≥59.5 flips/s remains unverified:** this sandbox has no Metal device and denies macOS `sample` task inspection.

Root cause: GET acknowledged completed RSX decoding/encoding, making the PPU wait for Metal at each ring wrap. The supplied host measurement's ~6.4 ms of serialized recycling pushed frame preparation beyond one vblank. The retirement clock was already correct.

The runner now enables a separate **RSX copy worker**, staging complete command packets into **64 rotating 64 KiB host buffers (4 MiB including packet metadata)**. It publishes guest GET after copying, independently of the render lock. The existing ordered walker decodes from immutable host bytes. JUMP/CALL/RET successors resolve during copying; vertex/index/texture references remain execution-time reads. Labels, semaphore acquires/releases, references and reports execute only on the consumer. Direct flips use monotonic command tickets rather than recycled ring offsets; a boundary armed during an active render slice prevents later commands passing it. FIFO flips still hold following commands through presentation, and T's retirement gate remains unchanged. A full host queue applies backpressure. Explicit FIFO reset and termination clear staging safely.
