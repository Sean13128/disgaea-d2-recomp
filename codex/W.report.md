# W — alternating silent audio blocks

Fixed the generic runtime clock in `ps3recomp/libs/audio/cellAudio.c`. An open device previously disabled time pacing: available device room alone drove consumption and notifications. A host callback consuming 512 frames frees two PS3 blocks simultaneously. The runtime immediately mixed both 256-frame blocks, advancing the read index twice before the asynchronous guest mixer could fill the second. The average 187.5 blocks/sec hid this burst timing; it produces the observed 93.75 Hz gating.

Both POSIX and Windows now apply the existing monotonic 256/48000-second deadline with a device open, retaining device room as backpressure. SDL output logging also reports the obtained callback sample count. No guest overrides, altered ring clearing, duplicated PCM, or synth2 protocol changes were needed.

Changed files: SDK `libs/audio/cellAudio.c`; `patches/W-audio-clock.diff`; `codex/W.audio-clock.c` (asynchronous producer / 512-frame device regression); `codex/W.analyze.py` (block RMS, lag-1/2 correlation, odd/even contrast, PCM WAV conversion); `codex/W.host-check.sh`; `.gitignore` allows these three W tools; this report. Only `port/build-w` was configured/built using OPERATIONS.md's exact flags. No game dump changes, commits, or pushes.
