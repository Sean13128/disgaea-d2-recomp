# Disgaea RPG appearance importer implementation

The active objective is a reusable toolchain that imports multiple Disgaea RPG characters as alternate appearances in this Disgaea D2 recompilation. **Implementation is in progress; no playable appearance has been installed or validated.** Original source assets, primary saves and installed app remain unchanged. Opt-in experimental runtime bindings are implemented below and default to OFF.

## Implemented components

- `tools/d2_rpg_assets.py` extracts a selected RPG character's original atlases, sprites, prefab objects and animation metadata. Liones Princess Etna 84 is available under `work/rpg-original-etna84`, with hashes and named sprites.
- `tools/d2_asset_pack.py` now compresses the actual D2 dat-LZS format and rebuilds NISPACK archive copies with member replacements or additions. It preserves original member order, name bytes and unknown directory words; it verifies all member bytes after rebuilding and checks the source archive hash. Additions accept explicit unknown directory words, defaulting to zero; runtime semantics remain unverified. The appearance staging tool inherits the donor's directory word. Outputs must be new files; sources and symlink paths are protected.
- `tools/d2_anm.py` now inspects the internal resource blocks and ten metadata table geometries in ANM data. It checks count/stride/offset bounds, resource-block termination, texture/palette payloads and page counts. Rectangle and transform records are exposed as candidates; they are not yet a complete native animation decoder.
- `tools/d2_rpg_map.py` suggests named pose mappings using a reference RPG character, with horizontal mirroring and explicit source crops/destination placements. Its builder patches selected indexed regions, preserves every metadata/palette byte and all other texture bytes, checks source hashes and rectangle correspondence, rejects overlapping patches, compresses the result and exports every affected palette variant. A walking preview uses decoded output crops with illustrative timing. The current build mode is an offline texture diagnostic; it does not install an appearance.
- `tools/d2_appearance_probe.py` compiles the exact 1.40 resource-manager and enabled-query functions with declared VM/dependency stubs. It verifies separate resource descriptors, native filename generation, reuse and full-bank behavior with AddressSanitizer/UndefinedBehaviorSanitizer. Filename formats come from the matching 1.40 ELF rather than an assumed string.
- `tools/d2_appearance_stage.py` authors a separately numbered resource and four patched character-table variants inside independent content/HDD0 copies, with an empty HDD1 cache. It preserves the original resource, rejects existing candidate filenames and source symlinks, checks available space and validates archive/source hashes. An optional plaintext save diagnostic selects the alternate and updates its cached primary body; it preserves the secondary body and all other save bytes. This is an isolated runtime experiment, not an installation command or a validated menu option.
- `port/src/d2_appearance_trace.cpp` and `port/src/d2_appearance_lift.cmake` add optional read-only traces around exact 1.40 selection, body read/write and resource-manager update functions. `D2_APPEARANCE_DIAGNOSTICS` defaults to OFF. The private `port/build-rpg-import` was configured with it ON and built successfully. Runtime tracing is enabled by `D2_APPEARANCE_TRACE=30000`. Original lifted files remain unchanged; only build copies are renamed.
- Four asset-free CTest targets, `d2.asset-pack`, `d2.anm-metadata`, `d2.rpg-mapping` and `d2.appearance-stage`, exercise fifteen unittest methods. New checks cover explicit addition words, internal resource-ID rebinding, secondary selector authoring, independent cloned files, symlink refusal and isolated save edits including cached bodies. All four targets pass. The mapping tests require Pillow and report a skip if it is unavailable.

## Verified real asset results

Etna's expanded ANM is 2,499,472 bytes. New compression produces 618,929 bytes versus 639,429 bytes in the supplied archive. Decompression is byte-identical to the original, closing the earlier literal-only compression limitation for this asset. This is a decoder roundtrip and packaging result, not guest runtime validation of the compressed stream.

`work/appearance-development/codec-baseline-ANM_HI.dat` is a rebuilt private archive copy with Etna recompressed. No live content has been redirected to this baseline.

The metadata inspector passes six actual ANMs: resources 00001,00002,00003,00010,00030 and 00410. The global resource-block count and cumulative block lengths exactly terminate at the texture-header table. Common `anm00001.lzs` contains 12 resource blocks; the first resource 1 block has 248 tag entries,4,358 track records and 14,347 key records. This split shows why a body-only importer is insufficient: shared metadata includes rectangle candidates associated with page numbers absent from a given character's own page set, and special-case body metadata overrides some shared definitions. The native binding rules need tracing before those candidates can become authoritative replacement destinations. Private JSON inspection results for Etna and the common library are saved alongside the packaging baseline.

Install Pillow for the mapping tool and UnityPy for extraction into an isolated Python environment. Extract the target and a reference corresponding to the D2 donor with `tools/d2_rpg_assets.py`. From the repository root, use new output directories:

```sh
python3 -B tools/d2_rpg_map.py suggest \
  --archive 'Disgaea D2 A Brighter Darkness - [BLUS31313]/PS3_GAME/USRDIR/Data/ANM_HI.dat' \

  --output work/appearance-development/my-suggestions
```

Review `mapping.json`: verify pose matches and orientation, adjust placements if needed, and set `selected` to `true` for intended entries. Selection authorizes only offline conversion. There is no installation action. Then:

```sh
python3 -B tools/d2_rpg_map.py build \
  --archive 'Disgaea D2 A Brighter Darkness - [BLUS31313]/PS3_GAME/USRDIR/Data/ANM_HI.dat' \
  --manifest work/appearance-development/my-suggestions/mapping.json \
  --output work/appearance-development/my-build

  --output work/appearance-development/my-loader-probe.json \
  --scratch /Volumes/Data/ai-tmp/codex/my-unique-task
```

Use `--member` to select a different donor ANM. Visual proposals remain donor/reference dependent; the twelve Etna walking indices are not a universal character schema. ## Authored source colors — 2026-10-08

`tools/d2_rpg_palette.py` builds a coordinated source-color appearance from a reviewed composition. It validates all component maps through the existing composition pipeline, renders original RGBA sources into donor palette-zero atlases, rejects source RGBA conflicts even when old donor quantization masks them, and trains a single bounded Pillow FASTOCTREE palette. All ten texture pages are re-encoded using alpha-weighted nearest-color selection. Every native recolor slot receives the same authored colors; native recolors are deliberately suppressed in this mode. Unmapped regions retain donor palette-zero artwork, re-quantized into the new palette. They are not replaced with fabricated or arbitrary poses.

The original animation metadata, texture/palette headers, counts, dimensions and expanded length remain byte-identical. Only validated texture/palette payloads change.
