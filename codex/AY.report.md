# AY — multi-wait fan-out and FIOS QoS

Root causes: every changed compatibility object broadcast the global multi-wait condition, waking RSX for unrelated objects; every guest PPU worker was assigned interactive QoS. A regression test also exposed wait-all holding `s_lock` in a busy loop after one timer became ready, preventing the remaining event from being signaled.

**Counter findings / decision.** Instrumentation came first, with AW+AX retained. Initial 60 s hub (`port/runs/AY-host.yD3TAx/control/game.log:6347,7347,8340`) averaged 208.7 useless RSX wakes/s: below the suggested threshold. Extended FIFO-only battle diagnostic (`port/runs/AY-battle-settled.wocBkW/battle.log:20065,24917,29770`) measured **1,952.6/s** over three settled 10 s intervals; startup exceeded 10,000/s. This justified fan-out. Final hub/title/battle summaries all report zero useless wakes. These are condition returns, not measured context switches or interrupt wakeups.

**Changes.** `runtime/platform/win32_compat.c` registers a stack waiter, its object references, and a private condition under `s_lock`; notification visits only subscribers. State checks/consumption remain under that lock. Unregister/cancellation removes subscriptions before releasing references or destroying the condition. Kick, rearm, auto-reset, wait-all, timeout and close behavior are preserved. Ready timers no longer force wait-all to spin. `PS3_MULTIWAIT_BROADCAST=1` restores global notification. `PS3_MULTIWAIT_STATS=1` emits approximately 10 s global change/broadcast/private-notification and per-thread wake/interest/useless/timed-return summaries, without a stats timer. “Interest” means at least one subscribed object was signaled; timer rearm/spurious/competing-consumer wakes can legitimately have none.

`runtime/syscalls/sys_ppu_thread.{c,h}` adds weak `ps3_ppu_thread_interactive(name)`, default 1. `port/stubs.cpp` returns 0 only for `fios mediathread*` / `fios scheduler*`, selecting existing `QOS_CLASS_DEFAULT`; `PS3_D2_FIOS_QOS=interactive` restores their old policy. PPU main, RSX, cellAudio, mixer, synth2 and NisAt3Line retain their current QoS. All twelve FIOS workers log default in full mode (`full/game.log:82–129`). AW/AX changes remain intact.

Also changed: SDK `runtime/platform/tests/test_win32_compat.c`; port `tests/CMakeLists.txt`, `tests/AY.qos-test.cpp`; `codex/AY.{headless,host}-check.sh`; `patches/AY-runtime.diff`. SDK export contains only AY differences against the initial shared-tree snapshots, including the syscall files' small hook additions; reverse apply --check passes. No commit/push, game-dump modifications or other build-directory writes. Disposable save copies/snapshots were removed.
