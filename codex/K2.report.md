# K2 — movie playback follow-up

Fixed the codec causes and added complete offline/host verification. **Real VideoToolbox playback still requires Claude's host rerun**: this sandbox still rejects session creation with `-12911`.

## Root causes

- **AU 32, 17,968 bytes:** PPS 0 changes from `28ea805fcc03` to `28eac05fcc03`, enabling weighted prediction on a non-IDR P picture. The old decoder discarded reference pictures by recreating VT sessions on every parameter-set change. AU 21 already changed initial QP to -23 on a non-IDR picture. There are 98 configuration transitions, 46 on non-IDRs. Compatible descriptions now update through `VTDecompressionSessionCanAcceptFormatDescription` without resetting references; SPS/PPS remain in AVCC samples. Incompatible changes restart at IDR.
- **AU 33, 4,795 bytes:** the standalone test stopped after AU 32's error and flushed the pending fragment from its first 65,521-byte input chunk. Actual AU 33 is 22,615 bytes. Tests now flush pending video only at real EOF. Strict decoding reproduces/rejects this exact truncation.
- Sparse PES timestamps left most VT samples untimed. Added bounded HRD/SEI parsing and complete DTS/PTS, including B-picture display delays, shared with the offline checker. No per-AU delayed-frame flush.
- Immediate/deferred bad-data errors now drain/reset and skip to IDR without sending D2 a fatal vdec error. Recovery is logged and **fails** host verification; missing pictures cannot be concealed.
- **Audio is not silent:** opening PCM blocks 1-347 are silent; first sound is block 348. Full decode: 2,733 blocks, peak `1.216927`, zero errors. No audio decoder modification was needed.

## Stream findings

All 2,793 AU boundaries match independent FFmpeg parsing, including PES/input splits. Every picture has four slices (first macroblocks 0/800/1760/2560), 1280x720 progressive: no PAFF/MBAFF, incomplete full-stream AUs or merged pictures. One SPS, eleven PPS variants; 14,488 three-byte and 3,131 four-byte start codes; zero trailing zeros. Emulation-prevention bytes stay intact. Every NAL size/prefix is in `port/runs/K2-nal.log`; FFmpeg headers are in `K2-full-headers.log`.
